# Changelog

## 1.0.0 (2026-11-17)

First tagged release.

- Ranks covered-call candidates from an option chain by annualized yield, with flags for earnings, dividends, thin markets and wide spreads.
- `roll` command to check whether to roll an open call.
- Charts for payoff against holding the stock, yield by strike and expiry, risk flags and delta.
- Tests run on GitHub Actions for every push and pull request.
- Contributing guide and issue templates.
